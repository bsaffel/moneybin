`sync login` now saves the sync server address to the profile: pass `--server <url>` once, or answer the prompt on a terminal, and later commands need no environment variable (MCP: `sync_link(mode="login", server_url=...)`, saved only after you confirm a prompt). `MONEYBIN_SYNC__SERVER_URL` still overrides the saved address. Stored sync tokens are now bound to the server that issued them, so changing the address never sends them elsewhere.
