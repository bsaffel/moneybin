`sync login` now saves the sync server address to the profile: pass `--server <url>` once, or answer the prompt on a terminal (press Enter for a local server at `http://127.0.0.1:8000`), and later commands need no environment variable (MCP: `sync_link(mode="login")` offers the same local address, or pass `server_url=...`; either is saved only after you confirm a prompt). `MONEYBIN_SYNC__SERVER_URL` still overrides the saved address. Stored sync tokens are now bound to the server that issued them, so changing the address never sends them elsewhere.
