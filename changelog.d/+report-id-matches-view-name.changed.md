Four report ids and their CLI commands now match the `reports.*` view each one reads: `reports cashflow` is `reports cash-flow`, `reports spending` is `reports spending-trend`, `reports recurring` is `reports recurring-subscriptions`, and `reports merchants` is `reports merchant-activity`. The old spellings are unregistered rather than aliased, so a script or saved prompt using one fails with an unknown-command or unregistered-report error and must switch to the new name.
