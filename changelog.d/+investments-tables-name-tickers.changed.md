`investments list`, `holdings`, `gains`, and `lots list` now name each security by its ticker (or its catalog name when it has none; a ticker two catalog entries share is written with its exchange, as `UMAX.AX`) instead of its catalog id, which moves to a `security id` column under `--wide`; `investments list` gains `--wide`, `securities list` heads its id column `security id`, and the JSON rows add `ticker`, `security_name`, `exchange`, and `ticker_shared` beside `security_id`.
