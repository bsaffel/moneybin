A headerless CSV or Excel file whose dates use a format outside the built-in detection list (for example `%Y%m%d`) no longer loses its first transaction to header detection when `moneybin import files` is given `--date-format` or a saved format via `--format`, or when `moneybin import preview` is given that same `--format`. MCP's `import_files`/`import_preview` take no date-format input, so those surfaces are unaffected.
