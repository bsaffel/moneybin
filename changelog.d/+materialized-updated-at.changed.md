`updated_at` on the FX conversions, currency lots, realized FX gains and investment ledger no longer advances when an account is renamed or a transaction is annotated or categorized; it moves only when a value those rows hold changes. `moneybin investments prices set` and `delete` drop `--refresh` and their JSON `refreshed`/`refresh_error` fields, because a mark now values holdings as soon as it is saved, and `sync disconnect --purge` no longer asks for a refresh afterwards.
