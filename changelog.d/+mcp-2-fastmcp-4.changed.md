The MCP server now runs on the 2026-07-28 protocol revision, via mcp 2.2.0 and fastmcp 4.0.5. Every tool now advertises a `title` alongside its name, which some hosts require in order to show the tool at all. The tool surface is unchanged otherwise — the same 50 tools, with the same names, descriptions, and arguments — and the recorded surface size moves from 62,356 to 63,711 bytes to account for those titles and for a one-byte-per-tool metadata key that the previous serialization had been dropping.
