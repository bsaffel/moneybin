`sql_query` now masks a protected value read through a source whose name shadows a catalog table: a `VALUES`, `UNNEST`, `LATERAL`, `PIVOT`/`UNPIVOT`, table function, or aliased CTE. A column read through a pivot no longer takes the class of the catalog column it is named after. Before this fix, both shapes, read directly or from a correlated subquery, returned the value unmasked at tier LOW.
