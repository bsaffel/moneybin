`sql_query` now classifies each column by the source its `FROM` actually binds, so a protected value no longer comes back unmasked at tier LOW through a `VALUES`, `UNNEST`, `LATERAL`, `PIVOT`/`UNPIVOT`, table-function, or aliased-CTE source named after a catalog table. The same fix covers a column-list alias, an alias reused in another scope, and a correlated subquery reading any of these.
