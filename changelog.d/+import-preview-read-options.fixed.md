`moneybin import preview` now reads and reports a file the way the `import files` or `import confirm` invocation it previews will. It accepts `--date-format` and `--number-format`; it applies every read setting a `--format` names — sheet, skip rows, file type, delimiter, encoding and trailing-row patterns — rather than only the date format; and it reports a declared date format the loader will accept even when detection's stricter bar rejects it. Previously a preview could report a header row, another worksheet's columns, or one transaction fewer than the import itself would load — including when the preview command came from MoneyBin's own printed recovery hint.
