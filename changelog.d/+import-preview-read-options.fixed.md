`moneybin import preview` now reads and reports a file the way the `import files` or `import confirm` invocation it previews will. It accepts `--date-format` and `--number-format`; it applies every read setting a `--format` names — sheet, skip rows, file type, delimiter, encoding and trailing-row patterns — rather than only the date format; and it reports a declared date format the loader will accept even when detection's stricter bar rejects it. Previously a preview could report a header row, another worksheet's columns, or one transaction fewer than the import itself would load — including when the preview command came from MoneyBin's own printed recovery hint. It now holds the date format to that same loader gate on both paths: a `--format` preview no longer announces a format the import goes on to refuse, and an Excel file's native date cells are rendered into the declared format before the format is judged, so one the import accepts is no longer previewed as unreadable.
