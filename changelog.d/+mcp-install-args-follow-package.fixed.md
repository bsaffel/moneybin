`moneybin mcp install` chooses between `uv run --directory <checkout>` and the published `uv tool run --from moneybin==<version>` from where the running package is installed, not from the current directory, so running a checkout's code from a subdirectory no longer writes a config that cannot resolve. When the data home install resolved differs from the one the launched server would open, the entry pins it with `MONEYBIN_HOME`.
