`moneybin import confirm` now accepts `--format`, `--date-format`, `--number-format`, `--sheet`, `--delimiter`, and `--encoding`, and every recovery command MoneyBin prints (from `import files`, `import confirm`, and `import preview`) carries whichever of these options the original invocation used. Previously a retry command dropped them, so re-running it against a file that needed a non-default format, sheet, delimiter, or encoding could read the file differently than the invocation that produced the proposal.
