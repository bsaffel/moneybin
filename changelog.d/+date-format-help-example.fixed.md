The `--date-format` help on `moneybin import files`, `import confirm`, and `import preview` printed its example as `%%Y-%%m-%%d`. `%%` is how a strptime format spells a literal percent sign, so the example copied verbatim matched the eight characters `%Y-%m-%d` and no date at all, and the import it was meant to demonstrate was refused. It now reads `%Y-%m-%d`, on all three commands and in the generated CLI reference.
