`core.fct_investment_transactions`, `fct_investment_lots`, `fct_realized_gains`, `dim_holdings`, `fct_currency_lots` and `fct_realized_fx_gains` gain a derived `reconciliation_status` (`reconciled` / `unreconciled`) marking every row of an account with two investment sources, cleared by choosing one with `accounts set --investment-source-type`; the CLI tables add a `reconciliation` column when a row is unreconciled, lot selection warns, the bundle manifest reports `unreconciled_row_count` per carrying table, and a `moneybin_reconciliation_unreconciled_accounts` gauge counts the affected accounts.
