`reports.net_worth.unanchored_account_count` — `net_worth` (and `total_assets`/`total_liabilities`) is now NULL while an eligible account with priced holdings or transaction activity has no balance observation at all, the way an unpriced currency already NULLs the total. `reports.net_worth_accounts` synthesizes a row for such an account, with every balance-derived column NULL and `is_observed = FALSE`, instead of the account being invisible on the per-account rung. Two new `core.*` views back the guard: `core.dim_holdings_broker_reported` reduces each Plaid item's newest holdings snapshot to one broker-reported position per account, and `core.dim_unanchored_accounts` is the shared candidate relation both net-worth rungs, the report runners, and `system doctor` read. Two `moneybin system doctor` checks close the release gate: `net_worth_unanchored_accounts` (`fail`) flags an eligible account holding value with no balance observation, and `net_worth_stale_balance` (`warn`, threshold `doctor.balance_staleness_threshold_days`, default 30) flags an eligible account whose latest observed balance has aged past the threshold without blocking release.
