`moneybin system status --output json` now returns the same sectioned `data` as the MCP call `system_status(sections=["overview", "exports"])` — an overview section with the full inventory (review queues, transform freshness, Google Sheets health, database connections, build) and an exports section — in place of the flat `accounts_count` / `matches_pending` / `exports` object. Scripts reading the old keys find them under `data.sections[0].overview` and `data.sections[1].destinations`.
