`moneybin system status --output json` now returns the same sectioned `data` as the MCP call `system_status(sections=["overview", "exports"])` — an overview section with the full inventory (review queues, transform freshness, Google Sheets health, database connections, build) and an exports section — in place of the flat object. Old keys map to `data.sections[0].overview.*` as `accounts_count` → `accounts.count`, `transactions_count` → `transactions.count`, `transactions_date_range` → `transactions.date_range`, `last_import_at` → `transactions.last_import_at`, `matches_pending` → `matches.pending_review`, `categorize_pending` → `categorization.uncategorized`; `exports` → `data.sections[1].destinations`.
