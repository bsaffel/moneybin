`core.fct_balances_daily` gains `in_net_worth` (between `is_observed` and `observation_source`) and carries rows with `balance` NULL for an account that holds value but has no balance observation; count those rows before trusting a `SUM(balance)`. The spine now ends at the newest evidence date in the profile — an observation, a transaction, a trade, or a broker-reported position — so an account is carried forward past its last statement to a later transaction, with that transaction applied. The `balances_daily` export carries both changes, `moneybin accounts balance show` and `history` list such an account as `no balance recorded`, and MCP `accounts_balances` returns its `balance` as null.
