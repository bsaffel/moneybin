Category text an imported file supplied no longer shows as a transaction's category on its own. It becomes one only once `moneybin categories mappings set` (or a `source_category` item in `taxonomy_set`) maps the term, so until then those transactions read as uncategorized and appear in `moneybin review`. `moneybin transactions list --uncategorized` now lists exactly the transactions the review queue offers, so it no longer includes transfer legs or rows on archived accounts, and `categorize stats` drops its `source_supplied` bucket.
